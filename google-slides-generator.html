One-time setup

This tool talks directly to your own Google account — it needs a Google Cloud OAuth Client ID that you create and control. No server, no third party ever sees your slides.
  1. Go to Google Cloud Console → APIs & Services → Credentials and create an OAuth client ID of type Web application.
  2. Under Authorized JavaScript origins, add https://mkuh-cmd.github.io (and http://localhost if you test locally).
  3. In APIs & Services → Library, enable the Google Slides API.
  4. Copy the generated Client ID and paste it below. It's saved only in this browser (localStorage).
